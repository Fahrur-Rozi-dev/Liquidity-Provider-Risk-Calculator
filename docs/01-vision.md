# Product Vision

## Name
Liquidity Provider Risk & Hedge Intelligence Platform

## Purpose
Help an LP researcher answer:

- What exactly is my LP position worth?
- How does it behave across price scenarios?
- What is my LP delta?
- How much hedge is needed?
- What happens under dynamic hedge/rebalance rules?
- How did a strategy perform historically?
- What real pool data supports the assumptions?
- What risks remain after fees and hedge?
- What should I monitor in realtime?

The platform is a research and decision-support system, not an execution terminal.

## Product Principles
1. Accuracy before visual complexity.
2. Transparent assumptions before attractive numbers.
3. Separate exact protocol math from estimates.
4. Separate historical facts from projections.
5. Every phase extends the system instead of replacing it.
6. Realtime means fresh data, not automatic execution.
7. A recommendation must be traceable to data and calculations.

## Core User
An LP researcher who provides position parameters manually and wants to understand concentrated liquidity risk with optional futures hedging.

## Supported Concepts
- Concentrated liquidity / CLMM
- Volatile + stable pairs
- LP vs HODL
- Impermanent loss
- LP delta
- Short hedge
- Dynamic hedge
- Threshold rebalance
- Funding cost
- Rebalance cost
- Historical backtest
- Real pool data
- LVR/adverse selection
- Volatility and range efficiency
- Realtime monitoring
- Alerts and recommendations

## Explicit Non-Goals
- Wallet management
- Transaction signing
- Trading
- Automated liquidity management
- Automated futures execution
- Custody
- Portfolio accounting for arbitrary wallets
